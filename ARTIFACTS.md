# Artifact manifest

This manifest classifies benchmark artifacts; it does not assert that every
JSON is a benchmark or committed to Git. Entries identify the generating script
and the claim supported by a historical run. Current code may differ: a preserved
artifact is not a rerun of repaired code. Check `git status` for tracking state.
Unlisted outputs are working artifacts, not publication claims.

Every file is listed **explicitly** — no globs. A wildcard entry silently fails
to cover a file added later, which defeats the point of a manifest.

Regenerate any entry with the script named in the same row, from the repo root.

## Conventions

- Seeded comparisons use **medians over seeds** with IQR where shown;
  `n_seeds` is recorded in those files. Deployment timings instead aggregate
  measurement passes, and single Metro runs are not multi-seed estimates.
- A median over an **even** number of integer observations is fractional
  (e.g. `7.5` failure rows). Print one decimal; do not round it to a "clean"
  integer — Python's `'{:.0f}'.format(7.5)` yields `'8'` and silently invents
  data.
- Paired tests are two-sided Wilcoxon on per-seed values. `wins_shd` is
  direction-aware: lower-is-better except for `*_r2`.
- Cost-model results (`bench_scania_cost_results.json`) satisfy
  `cost == 10·FN + 1·FP` per seed; the verifier asserts this identity.
