## 2. `bench_cmapss` — NASA C-MAPSS FD001 (20 сидов)

Конфигурация: `m=300`, `high_band_ratio ∈ {0.26, 0.5, 0.65}`, `batch=2500`,
`rul_cap=125`, критический порог `y≤25` (19 из 100 тестовых двигателей),
14 датчиков. Критический режим — низкий хвост (низкий RUL).

Оракул: KRR `rmse_crit=13.574` (весь обучающий пул); GBM full-pool
`rmse_crit=17.208`.

### Ключевые Wilcoxon-результаты (медианы по 20 сидам)

| Сопоставление | Медиана SHD | Медиана базового | Побед | p |
| :--- | ---: | ---: | :---: | :--- |
| SHD r=0.65 KRR крит. против Random | 14.525 | 18.050 | 16/20 | 0.00199 |
| SHD r=0.65 KRR крит. против KT | 14.525 | 17.517 | 16/20 | 0.00558 |
| SHD r=0.65 GBM крит. против Random | 14.005 | 19.772 | 18/20 | 6.3e-05 |
| SHD r=0.65 GBM крит. против KT | 14.005 | 18.135 | 18/20 | 0.00032 |
| SHD r=0.65 GBM крит. против SKT | 14.005 | 17.983 | 18/20 | 9.5e-06 |
| SHDU r=0.65 KRR крит. против Random | 13.447 | 18.050 | 17/20 | 0.00039 |
| SHDU r=0.65 GBM крит. против KT | 12.735 | 18.135 | 19/20 | 1.3e-05 |

### Сопоставление с оракулом (`vs_oracle` секция)

| Кристалл | KRR крит. | Побед над оракулом | GBM крит. | Побед над оракулом |
| :--- | ---: | :---: | ---: | :---: |
| SHD r=0.26 | 14.941 (оракл 13.574) | 4/20 | 16.132 (оракл 17.208) | **13/20** |
| SHD r=0.5 | 15.509 | 5/20 | 15.415 | **16/20** |
| SHD r=0.65 | 14.525 | 8/20 | **14.005** | **19/20** |
| SHDU r=0.65 | **13.447** | 10/20 | **12.735** | **19/20** |

Вывод: SHDU r=0.65 (GBM) почти догоняет full-pool оракул (12.74 против 17.21,
19/20 побед); на KRR SHDU r=0.65 (13.45) даже лучше KRR-оракула (13.574) по медиане.
По «всем строкам» (all) все варианты проигрывают full-pool оракулу (0/20 побед) —
кристалл оптимизирован под критический режим, а не под глобальную точность.
Время прогона: 1012.3 с.

## 3. `bench_pm25` — Beijing PM2.5 (20 сидов)

Конфигурация: всего 41,757 строк; обучение 33,406; тест 8,351;
критических строк теста — 374 (порог 324.0); 14 признаков.

Ключевые медианы (SHD): KRR RMSE все = 95.083, крит. = 231.010, R² = −0.017;
GBM: все = 86.111, крит. = 211.909, R² = 0.166.

| Сопоставление | SHD | Базовый | Побед | p |
| :--- | ---: | ---: | :---: | :--- |
| KRR все против Random | 95.083 | 88.237 | 3/20 | 0.00039 |
| KRR все против KT | 95.083 | 89.887 | 2/20 | 8.2e-05 |
| KRR крит. против Random | **231.010** | 248.920 | 15/20 | 0.01208 |
| GBM все против KT | 86.111 | 79.848 | 2/20 | 4.8e-05 |
| GBM крит. против KT | **211.909** | 228.814 | 14/20 | 0.06372 |
| GBM крит. против SKT | **211.909** | 221.185 | 14/20 | 0.04844 |

**Отрицательный результат для глобальной точности**: медиана R² (KRR) отрицательна
(−0.017), SHD проигрывает Random/KT/SKT на «все строки» по обоим моделям
(p до 5.7e-06). Кристалл сохраняет преимущество только в критическом режиме
(GBM крит. 14/20 против KT, 14/20 против SKT) — см. раздел «Известные ограничения»
в README. Время прогона: 909.3 с.

## 4. `bench_metro_watch` v2 — MetroPT-3 (протокол v2)

Протокол: learn 02.02–15.03.2020, calibrate 15.03–10.04, watch 10.04–01.08,
окно 60 мин / шаг 30 мин, cooldown 6 ч, бюджет ложных тревог 1.0/мес,
EWMA-полусрок 7 дней, горизонт предсказания 21 день.
Всего 252,720 минут; калибровочное окно — 994 окна, наблюдательное — 4,192 окна
(2.869 наблюдаемых месяцев, календарно 3.767).

### Результаты по пяти армам (текущий артефакт, v3.13.0)

| Арм | tau | Утечек найдено | Лиды (ч) | Эпизоды | Ложные/мес (набл.) |
| :--- | ---: | :---: | :--- | ---: | ---: |
| shd_detrend (SHD паспорт) | 0.621 | **0/4** | — | 0 | 0.000 |
| z_detrend (z-фичи) | 12.325 | **4/4** | 131.3 / 392.9 / 415.4 / 163.7 | 15 | 1.743 |
| iforest_detrend | 0.224 | 2/4 | 392.4 / 394.6 | 2 | 0.000 |
| shd_raw (SHD паспорт, без detrend) | 1.192 | 0/4 | — | 0 | 0.000 |
| **shd_radar (v3.13.0)** | **11.549** | **4/4** | 131.3 / 393.4 / 436.4 / 0.0 | 13 | **0.697** |

**Ключевое изменение v3.13.0:** арм `shd_radar` — новый комбинированный радар
(BW-расстояние + mean-shift-расстояние). До исправления масштаба в
`_mean_shift_distance` tau взрывался до ~3.86e7 (причина: `X_std` из первого
батча 4000 мин, LPS почти постоянна → z-оценки ~3.9e7). После перехода к
масштабу облака меаноидов всего обучающего окна (300 реальных строк)
tau = 11.549 — разумное значение, и радар находит все 4 утечки с лидами
5.5–18.2 дня при ложных срабатываниях 0.697/мес — **в пределах бюджета 1.0/мес**.

Остатки артефакта (текущий файл): кристалл 55.5 КБ, learn 6.2 с, scan 36.8 с, весь прогон 177.0 с.
Истинные инциденты — из `metro_incidents.json` (4 утечки, все «High stress»).
